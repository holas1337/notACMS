Cette page est la référence design vivante pour notACMS. Elle documente tous les composants nommés, propriétés CSS personnalisées et patterns Twig utilisés dans le thème par défaut.

> **Note :** Les noms de composants et les identifiants de classes CSS sont des identifiants techniques — ils restent en anglais. Par exemple : `.feature-card`, `.sidebar-nav`, `--accent`, `ph-rocket`.
