Diese Seite ist die lebende Design-Referenz für notACMS. Sie dokumentiert alle benannten Komponenten, CSS Custom Properties und Twig-Muster, die im Standard-Theme verwendet werden.

> **Hinweis:** Komponentennamen und CSS-Klassenbezeichner sind technische Identifikatoren — sie bleiben auf Englisch. Zum Beispiel: `.feature-card`, `.sidebar-nav`, `--accent`, `ph-rocket`.
