> **Avis de démonstration :** Ce site de démonstration a `RUNTIME_PHP_ENABLED=false` dans le fichier `.env`, ce qui signifie que le formulaire de contact est désactivé. Pour l'activer, définissez `RUNTIME_PHP_ENABLED=true` et redémarrez les conteneurs. Consultez le [Manuel](/fr/manuel/) pour plus de détails.

Vous pouvez toujours me contacter sur [GitHub](https://github.com/holas1337/notACMS) ou via [holas.pl/contact](https://holas.pl/contact/).
