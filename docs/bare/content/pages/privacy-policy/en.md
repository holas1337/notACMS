## Data Collection

This site is generated by notACMS — a static site generator. It produces plain HTML files with no server-side processing, no databases, and no tracking by default.

## Cookies

The only cookie used is a functional cookie to remember your cookie preference (accepted or dismissed). No analytics cookies are set unless you configure a third-party analytics token in `_site.yaml`.

## Contact Form

If the contact form is enabled, form submissions are sent via email. The data is not stored on the server beyond the email delivery. A Cloudflare Turnstile challenge is used to prevent spam.

## Third-Party Services

If configured, the site may load:

- **Cloudflare Analytics** — only if `cf_analytics_token` is set
- **Cloudflare Turnstile** — only on the contact page, if enabled
- **Google Fonts** — only if the theme includes them (the bare theme does not)
