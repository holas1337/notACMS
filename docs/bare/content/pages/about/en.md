## What is notACMS?

notACMS is a static-first content management system built on Symfony. It generates plain HTML from Markdown content — no database, no server-side rendering at runtime, no surprises.

Write your content in Markdown. Define your site structure in YAML. Run one command. Deploy the output.

## Built with

- **Symfony 7** — framework, routing, dependency injection
- **Twig** — template engine with full override support
- **AssetMapper** — modern asset management, no Node.js required
- **Pagefind** — static full-text search
- **DDEV** — containerized development environment
- **nginx** — production-ready static serving
